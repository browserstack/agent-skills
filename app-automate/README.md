# App Automate skills

Each skill takes a coding agent from a pasted prompt to a build on the BrowserStack App Automate dashboard.

| Framework | Language | Platforms | Skill |
| --- | --- | --- | --- |
| Appium | Python | Android, iOS | [`appium-python`](appium-python/SKILL.md) |
| Appium | Java (TestNG) | Android, iOS | [`appium-java`](appium-java/SKILL.md) |
| Appium | JavaScript (WebdriverIO) | Android, iOS | [`appium-javascript`](appium-javascript/SKILL.md) |

## Prompt

Replace `appium-python` / `Appium Python` with your skill:

```
Read https://raw.githubusercontent.com/browserstack/agent-skills/app-automate-v1.0.0/app-automate/appium-python/SKILL.md, install it as a skill in this project, then follow it to run the Appium Python sample build on BrowserStack App Automate.
```

To integrate your own suite instead of the sample, replace "the Appium Python sample build" with "my own Appium Python tests".
