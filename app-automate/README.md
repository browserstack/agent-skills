# App Automate skills

Each skill takes a coding agent from a pasted prompt to a build on the BrowserStack App Automate dashboard.

| Framework | Language | Platforms | Skill |
| --- | --- | --- | --- |
| Appium | Python | Android, iOS | [`appium-python`](appium-python/SKILL.md) |
| Appium | Java (TestNG) | Android, iOS | [`appium-java`](appium-java/SKILL.md) |
| Appium | JavaScript (WebdriverIO) | Android, iOS | [`appium-javascript`](appium-javascript/SKILL.md) |

## Prompts

**Appium Python**
```
Download https://raw.githubusercontent.com/browserstack/agent-skills/main/app-automate/appium-python/SKILL.md and save it permanently in this project's skills folder as browserstack-app-automate-appium-python/SKILL.md, then follow that skill to run the Appium Python sample build on BrowserStack App Automate.
```

**Appium Java**
```
Download https://raw.githubusercontent.com/browserstack/agent-skills/main/app-automate/appium-java/SKILL.md and save it permanently in this project's skills folder as browserstack-app-automate-appium-java/SKILL.md, then follow that skill to run the Appium Java sample build on BrowserStack App Automate.
```

**Appium JavaScript (WebdriverIO)**
```
Download https://raw.githubusercontent.com/browserstack/agent-skills/main/app-automate/appium-javascript/SKILL.md and save it permanently in this project's skills folder as browserstack-app-automate-appium-javascript/SKILL.md, then follow that skill to run the Appium JavaScript sample build on BrowserStack App Automate.
```

To integrate your own suite instead of the sample, replace "run the Appium <language> sample build" with "run my own Appium <language> tests".
